# intent/ — цепочка артефактов инициатив

Одна папка на инициативу: `YYYY-MM-DD-<slug>/`. Шаблоны хранятся отдельно в `_templates/`:

```text
intent/
├── README.md
├── _templates/
│   ├── intent.md
│   ├── spec.md
│   └── plan.md
└── YYYY-MM-DD-<slug>/
    ├── intent.md
    ├── spec.md
    └── plan.md
```

Дерево показывает итоговый состав инициативы. Рабочие файлы появляются по очереди
и коммитятся по отдельности; все три шаблона сразу в папку инициативы не копируются.
`_templates/` — служебный каталог, а не инициатива.
Все изменения проходят через PR; слияние подтверждает человек.

Имена и даты:

- дата в имени папки — дата создания `intent.md` по часовому поясу `Europe/Moscow`;
  при принятии или возобновлении инициативы она не меняется;
- slug состоит из строчных ASCII-букв `a–z` и цифр, разделённых одиночными дефисами:
  `[a-z0-9]+(-[a-z0-9]+)*`;
- полное имя папки уникально; существующую инициативу не перезаписываем;
- `id` в `intent.md` — строка, совпадающая с полным именем папки `YYYY-MM-DD-<slug>`;
- `created` в `intent.md` совпадает с датой папки; в `spec.md` и `plan.md` это фактическая
  дата создания соответствующего файла;
- дату `accepted` заполняем только после принятия соответствующего артефакта человеком.

| Файл | Шаг | Кто пишет | Кто принимает | Статус в frontmatter |
|---|---|---|---|---|
| intent.md | 01 PLAN | инициатор своими словами; Codex только спрашивает и структурирует | product owner | draft → accepted / rejected |
| spec.md | 02b DESIGN | Codex по intent.md + skills; правит product owner | product owner (+ владельцы политик по помеченному) | draft → accepted |
| plan.md | 03b BUILD | Codex в режиме планирования; утверждает инженер | инженер | draft → accepted |

Правила:

- следующий файл не пишется, пока предыдущий не `accepted`;
- функциональный код не пишется, пока человек не примет `plan.md` и план не будет закоммичен;
  каркас среды создаётся отдельно на шаге 03a;
- принятый файл не переписывается молча: правка после принятия — отдельный коммит с причиной
  (это и есть метрика переделок из статьи);
- находки эксплуатации (шаг 06) входят сюда же новыми папками — так замыкается цикл.

Шаблоны: `intent/_templates/` от корня проекта.
