# intent/ — цепочка артефактов инициатив

Одна папка на инициативу: `NNNN-<slug>/` (номер сквозной, slug латиницей через дефис).
Внутри — три файла, которые появляются по очереди и коммитятся по отдельности:

| Файл | Шаг | Кто пишет | Кто принимает | Статус в frontmatter |
|---|---|---|---|---|
| intent.md | 01 PLAN | инициатор своими словами; Claude только спрашивает и структурирует | product owner | draft → accepted / rejected |
| spec.md | 02b DESIGN | Claude по intent.md + skills; правит product owner | product owner (+ владельцы политик по помеченному) | draft → accepted |
| plan.md | 03b BUILD | Claude в plan mode; утверждает инженер | инженер | draft → accepted |

Правила:
- следующий файл не пишется, пока предыдущий не `accepted`;
- принятый файл не переписывается молча: правка после принятия — отдельный коммит с причиной
  (это и есть метрика переделок из статьи);
- находки эксплуатации (шаг 06) входят сюда же новыми папками — так замыкается цикл.

Шаблоны: `docs/templates/`.
