# snmp2mqtt

Учебный проект для освоения AI-Native SDLC (Anthropic playbook) на языке Go.
По названию — мост SNMP → MQTT; что именно он делает, определяет `intent.md` первой инициативы.

Рабочая среда — приложение Codex. Шаг 00 завершён; следующий — 01 PLAN
(намерение первой инициативы). Go-модуля и реализации пока нет.
Изменения оформляются в отдельных ветках через PR; слияние подтверждает человек.

- Карта процесса, шаги и их статус: `docs/sdlc-roadmap.md`
- Артефакты инициатив (intent → spec → plan): `intent/`
- Основной контекст Codex: `AGENTS.md`
- Работа в Codex и соответствия прежней среды: `docs/codex-workflow.md`
- Политики проекта (с шага 02a): `.agents/skills/<name>/SKILL.md`
